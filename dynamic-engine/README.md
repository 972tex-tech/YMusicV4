# `:dynamic-engine`

Module detail for the one-line summary in the root [`AGENTS.md`](../AGENTS.md) — read this before working inside the module.

the engine host: wraps `:quickjs` (`DynamicEngine`) and serves host protocols to the remotely-updatable scraping JS (YouTube feed-shape changes ship without an app release). `DynamicEngine.create(client, appVersion, logger, engineJs = ENGINE_JS)` boots the whole `:engine-js` bundle (handlers wired BEFORE the eval via `QuickJsRuntime.create`'s configure hook, `versions` installed from C at create) and then health-checks it over the bundle-served `"init"` pipe (returns `backendVersion`, the bundle's self-declared revision; typed rejections `E20020` load / `E20021` health check). `engineJs` is the remote-update seam; `DynamicEngineManager` owns the current engine — `start(remoteJs?)` falls back to the baked-in baseline on a rejected remote bundle, `swap(newJs)` flips new work onto the new engine first, then retires the old one (`"shutdown"` pipe = SIGINT: the bundle's `lifecycle.ts` clears timers + runs `onShutdown` callbacks; bounded `awaitIdle` drain; force-close at the deadline). Implemented: **HTTP** — a global `HttpRequest` builder over the `"http"` pipe command, served directly on a `kmphttp.KmpHttpClient` (streaming both ways; Android resolves `:kmpHttp:core`'s jvm variant, i.e. real OkHttp), plus the **error contract**: JS `commandHandler(handler)` (handler gets `(src, out)`)/`JsEngineError` ↔ a per-command Kotlin method that `decodeEngineError`s the RESET into a typed `EngineError` (implements `kmpcommon.error.CodedError`) over structured RESET reasons (the typed `WireError` shape) — codes cross all tiers unchanged, classified at the origin (HOST_PROTOCOLS "Errors across the boundary"), plus **cookies** — the bundle's `Cookies.get(url): Record<string,string>` / `.set(url, setCookie)` (one `Set-Cookie` string or an array) over the one-shot `"cookie/get"` / `"cookie/set"` commands, served on an **app-provided** `cookieJar` (the platform store the WebView player shares — Android `CookieManager`, desktop `CefCookieManager`; values parsed via `kmphttp.parseCookie`). The engine's own HTTP client carries **NO jar** — the JS owns cookie POLICY: `logic/yt/cookies.ts` cooks every YouTube request's `Cookie` header from this store (CONSENT/SOCS synthesis — the legacy `YTHttpClientCookieStoreAndHeadersManager` role) and writes `Set-Cookie`s back, so cookie behavior ships in the remotely-updatable bundle and scraping + playback present one identity (`NO_COOKIES` = capability inert; `E20040` bad head/url / `E20041` jar threw), plus **cache** — a **scoped** streaming keyed blob cache (every op takes a scope first — independent partitions, e.g. a 10-item home-feed scope + a 100MB download scope; `Cache.setJson`/`getJson`/`setText`/`getText`/`delete`/`list` + streaming `put`/`get` callbacks) over one-shot `"cache/get|put|delete|list"`, values streamed to/from disk, each entry host-stamped `size`/`updatedAt`/`lastUsed` (lastUsed bumped on get → LRU) + a caller `meta` string-map; the store (`CacheStore`, shipped as `DiskCacheStore` — **metadata index in SQLite** (SqlDelight, so `list`/`init` is one indexed SELECT not a per-file dir scan) with **blobs on the okio `FileSystem`**, sha256(scope,key) filenames, atomic writes; the app passes a platform `SqlDriver` + blob dir) is **unbounded** and **eviction lives in the JS** — `scopedCache(scope, evictor)` drives a stateful `CacheEvictor` (`init(entries)` seeds from the scope, `onAdded(meta)` after every write→trim, `onRead(meta)` after every get refreshes lastUsed, `onDeleted(key)`), built-ins `keepCount(n)`/`lruCount(n)`/`lruSize(bytes)` or hand-written, so the policy is remotely updatable; wired via `DynamicEngine.create(cacheStore = …)` (absent → no cache; `E20050` bad head / `E20051` store threw). Its home is the InnerTube session params (client version / `sts` / `visitorData` / bootstrap feed). Planned: file / fs / sqlite. Pure commonMain; targets = `:quickjs`'s (jvm/android/ios/macos/linux). Protocol spec: [`quickjs/HOST_PROTOCOLS.md`](../quickjs/HOST_PROTOCOLS.md).
